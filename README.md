# QG • Candidato Irresistível

Painel simples de execução do projeto **Candidato Irresistível**.

- Mostra sprints concluídas, sprint atual e pendentes.
- Um único botão conclui a sprint vigente.
- O progresso é salvo automaticamente no navegador com localStorage.
- Estado inicial: sprints 01 a 05 concluídas; sprint 06 vigente.
